It draws a straight line through the data. The simplest model in our syllabus.

What output did I get when I used it?
Tried: none — fit directly. LinearRegression has no hyperparameters, so running a grid search on it would be a fake search.
Best setting: {} (no tuning)
Result: RMSE 1.0374, MAE 0.7046, R2 0.5149. Training time: 0.0 s.

Why did I not use it? / What is the issue if I use it?

KNNRegressor Task: regression
✘ NOT CHOSEN

What is this model? (simple words)
To predict, it finds the k most similar hours from training data and averages their temperatures.

What output did I get when I used it?
Tried: n_neighbors = [3, 5, 9, 15, 25, 35] with GridSearchCV.
Best setting: n_neighbors = 25
Result: RMSE 1.0941, MAE 0.7322, R2 0.4604. Training time: 0.5 s.

Why did I not use it? / What is the issue if I use it?

Problem: Slow at prediction time on big data (it compares with every training row). RMSE 1.0941 is clearly worse than LinearRegression.
NOT CHOSEN — worse score than the linear models, and it does not scale well.

RandomForestReg Task: regression
✘ NOT CHOSEN

What is this model? (simple words)
Many decision trees trained on random parts of the data, then their predictions are averaged.

What output did I get when I used it?
Tried: n_estimators = [50, 100, 200], max_depth = [5, 10, 15, None], min_samples_split = [2, 5] with RandomizedSearchCV (10 tries).
Best setting: n_estimators = 200, min_samples_split = 5, max_depth = 5
Result: RMSE 1.0612, MAE 0.7228, R2 0.4923. Training time: 29.0 s.

Why did I not use it? / What is the issue if I use it?
Good points: Handles non-linear relations. More stable than a single tree.
Problem: Slowest model we trained (29 seconds for 200 trees). Still worse than LinearRegression. Hard to explain tree-by-tree in viva.
NOT CHOSEN — slower and worse than LinearRegression.

SVR Task: regression
✘ NOT CHOSEN

What is this model? (simple words)
Support Vector Regression — it tries to fit a tube around the data and ignores small errors inside the tube.

What output did I get when I used it?
Tried: C = [0.1, 1, 10], gamma = ["scale", 0.01, 0.1] with GridSearchCV.
Best setting: C = 10, gamma = 0.01
Result: RMSE 1.0573, MAE 0.642, R2 0.496. Training time: 3.8 s.

Why did I not use it? / What is the issue if I use it?
Good points: Good at non-linear patterns. Interesting — it got the lowest MAE of all models (0.642).
Problem: RMSE (our selection metric) is worse than LinearRegression's. Sensitive to C and gamma, and needs scaled features.
NOT CHOSEN — lowest MAE is nice, but our rule picks on RMSE, and LinearRegression wins there.

KNNClassifier Task: classification
✘ NOT CHOSEN

To classify, it looks at the k most similar hours and takes a majority vote.

What output did I get when I used it?
Tried: k = [3, 5, 9, 15, 25, 35] with a manual CV loop — inside each fold the minority class was oversampled, so the validation scores stay honest.
Best setting: n_neighbors = 35

NOT CHOSEN — catches a lot but cries wolf too often.

DecisionTreeClf Task: classification
✔ USED AS FINAL MODEL

What is this model? (simple words)
It splits the data with yes/no questions (like "is temp > 7.5?") until it can say excursion or not.

What output did I get when I used it?
Tried: max_depth = [3, 5, 8, 12, None], min_samples_split = [2, 5, 10] with GridSearchCV, scoring on F1. Trained with class_weight="balanced".
Best setting: max_depth = 3, min_samples_split = 2
Result: accuracy 0.8889, precision 0.5862, recall 0.4595, F1 0.5152. Training time: 0.9 s.

Why did I not use it? / What is the issue if I use it?
Good points: Highest F1 of all models (0.5152, tied with RandomForest). Very easy to draw and explain in viva. Fast.
Problem: Single trees can overfit — but here the best tree was shallow (depth 3), so it stayed simple. Recall 0.4595 means it still misses about half the excursions.
CHOSEN — tied RandomForestClf on F1, and our tie-break rule says the simpler model wins.

Many decision trees trained on random parts of the data, then they vote.

Final choice

Regression (predict next-hour temperature): Linear Regression — RMSE 1.0374, R² 0.5149. Beat the persistence baseline (1.154) and every other syllabus model; trains instantly; first topic of Unit 2 in the official syllabus.

Classification (predict excursion): Decision Tree — accuracy 0.889, F1 0.515. Tied RandomForest on F1; the simpler model wins the tie (1 tree vs 100 trees, faster, easier to explain).

Honest limits: the classifier still misses about half the real excursions (recall 0.46); regression R² 0.51 is student-grade, not production-ready.
